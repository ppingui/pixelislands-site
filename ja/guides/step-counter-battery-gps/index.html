歩数計アプリはバッテリーを消費する？

2026年7月更新 · 読了目安7分

先に結論から。歩数を数えること自体は実質タダ。バッテリーを減らしているのはGPSです。iPhoneは専用の低消費電力ハードウェアで、フィットネスアプリを入れているかどうかに関係なく、一日じゅう歩数を数えています。その数字をヘルスケアから読み取るだけのアプリなら、コストはほぼゼロ。一方、GPSのセッションを開きっぱなしにするアプリ——ランニングの記録アプリ、地図ベースのゲーム、バックグラウンドで位置情報を見張っている類——はまったくの別物で、あなたが感じている電池の減りは、実際そこから来ています。

ですから、役に立つ問いは「この歩数アプリはバッテリーを使うのか」ではありません。「このアプリは無線機を使っているのか、それとも数字を読んでいるだけなのか」です。

iPhoneが歩数を数えるしくみ

最近のiPhoneには低消費電力のモーションコプロセッサが載っています。メインチップの中にある小さな専用ブロックで、加速度センサーとジャイロスコープを見張り、そこから歩数、上った階数、おおまかな活動の種類などを割り出すのが仕事です。ごく小さな電力で常時動き、メインCPUとは独立していて、画面がオフでもアプリが前面になくても動き続けます。

フィットネスアプリを一度も開いていない日の歩数データが残っているのは、そのためです。ヘルスケア → ブラウズ → アクティビティ → 歩数を開いてさかのぼってみてください。何も記録していなかったはずの数か月分の歩数が出てくるはずです。iPhoneはずっと数えていたのです。あなたがインストールしたものが、そのデータを作ったわけではありません。

これがバッテリーの話につながるのは、アプリについて示唆することがあるからです。HealthKitの上に成り立っている歩数計は、トラッキングを走らせているのではなく、すでに存在する数字をiOSに尋ねているだけ。処理はどのみち動いていたハードウェアが済ませています。それを読み返す作業は、動画の録画というよりテキストファイルを開くのに近いのです。

GPSが違う理由

GPSは、静かに見守るタイプのセンサーではありません。かすかな衛星信号を捉える無線受信機であり、位置を測り続けるということは、その受信機に電力を供給して計算させ続けるということです。しかもiOSはたいてい、それにWi-Fiや携帯電話網による測位も組み合わせるので、無線まわりの仕事はさらに増えます。

コストを押し上げる要因は3つあります。

  • 測位が継続的であること。ルート記録は1回の位置取得ではなく、散歩やランニングのあいだじゅう続く連続的な取得です。
  • たいてい画面表示とセットになること。地図ベースのアプリは見られるものです。ディスプレイはどんなスマホでも屈指の電力消費源であり、位置情報系アプリはそれをつけっぱなしにさせがちです。
  • バックグラウンドでも動きうること。位置情報を「常に許可」されたアプリは、あなたがまったく使っていないときにも起動して位置を取り直せます。夜のあいだに謎の電池減りとして気づかれるのが、まさにこれです。

これは別に不祥事ではありません。ランニングアプリはGPSなしにルートを描くことも、1kmごとのペースを出すことも、実距離を測ることも本当にできません。位置情報ベースのゲームは、あなたがどの公園にいるのかを本当に知る必要があります。電池の消費は、あなたが望んだ機能の正直な対価です。問題になるのは、その対価を払わせておきながら、それを必要とする機能を何も提供していないアプリだけです。

本当の犯人を見つける方法

推測は不要です。iOSが直接教えてくれます。

設定 → バッテリー。充電グラフを通り過ぎて、アプリごとの内訳までスクロールします。だいたい直近1日と、直近1週間〜10日ほどを切り替えられます。役に立つのは長いほうの期間です。たまたま変わった過ごし方をした午後の影響がならされるからです。各アプリについて、バッテリー使用の割合が表示されます。

「画面オン」と「バックグラウンド」の内訳を読む。アクティビティの表示に入ると、各アプリが画面上でどれだけ動いていたか、バックグラウンドでどれだけ働いていたかがわかります。ここが肝心です。使用量が多くて画面時間も長いなら、それは単にあなたがスマホを使っただけ——楽しんだSNSやゲームです。使用量が多いのに画面時間は短く、バックグラウンドの時間が長いというのが怪しいパターン。あなたが見ていないあいだに何かが働いているということです。

設定 → プライバシーとセキュリティ → 位置情報サービス。ここには、すべてのアプリとその位置情報の許可設定——なし、次回確認、使用中のみ、常に——が一覧で並びます。上から順に見て、「常に」になっているアプリについて、閉じているときにも位置情報が本当に必要かを自問してください。天気アプリがときどき状況を確認するのは妥当。買い物アプリや単純な歩数計は妥当ではありません。「常に」になっていて横に白抜きの矢印アイコンが付いているものは、最近あなたの位置情報を使ったという印です。

この2つのリストを突き合わせましょう。バッテリーの上位に来ていて、ほとんどがバックグラウンドの時間で、なおかつ位置情報が「常に」——それがほぼ確実に犯人です。「使用中のみ」に下げるだけで、たいていは削除しなくても解決します。

もうひとつ切り分けておきたいこと。バッテリーではなく数字のほうがおかしいのなら、それは別の問題です。Apple Watchの歩数が同期されないときをご覧ください。

歩数トラッカー選びのチェックポイント

インストール前に確認できる、短いチェックリストです。

  • 独自のトラッキングではなく、ヘルスケアから読み取っている。ただで手に入るデータのほうが、同じ作業を二重にやるより優れていますし、初日から履歴がそろっているという利点もあります。
  • 位置情報の「常に許可」を求めてこない。歩数アプリがバックグラウンドの位置情報を要求してきたら、どの機能に必要なのか考えてみてください。正直な答えはたいてい「広告のため」です。
  • 通知を連発するのではなく、ウィジェットを用意している。ウィジェットはホーム画面で安価に更新されますが、通知の連打はアプリが繰り返し起こされているということです。
  • バックグラウンド音声の小細工をしていない。バックグラウンドで生き延びるためだけに無音の音声を再生するアプリがあります。よく知られた抜け道ですが、何の見返りもなく実際に電池を食います。
  • 1週間使ってから、そのアプリのバッテリー欄を確認する。設定 → バッテリーの一覧こそ唯一意味のあるベンチマークです。あなたのiPhoneで、あなたの使い方で測られているのですから。

Pixel Islandsはどうしているか

自分たちのチェックリストである以上、自分たちにも当てはめるのが筋でしょう。Pixel Islandsはヘルスケアから歩数を読み取るだけで、センサーに関してはそれ以外に何もしていません。位置情報の許可はいっさい求めません。セットアップ中にGPSの確認画面が出ないのは、それを使うコードが存在しないからです。あなたの歩数は島を8つのステージへ育てていきますが、そのために必要なのは数字であって、地図ではありません。

結果として、バッテリー面のコストは実質ゼロで、設定 → バッテリーの一覧にそもそも目立って現れないことがほとんどです。これは私たちの技術がすごいという話ではありません。上の表の1行目にとどまっているアプリなら、当たり前にそうなるというだけのことです。

バッテリーに触れない歩数トラッカー 毎日の歩数で、ほっこりした島を育てよう。iPhoneで無料、ヘルスケア連携、位置情報アクセスなし。

同じ選択の、プライバシー側の話

GPSなしを選ぶ理由はバッテリーだけではありません。歩数はただの数字で、歩いたことは示しても、どこを歩いたかは示しません。位置情報の履歴は、まったく別のカテゴリーの情報です。

これはたいていのソフトウェア以上に、ウォーキングアプリにとって重い話です。歩くルートは、驚くほど多くを物語るからです。数日分の記録があれば、どこで眠り、どこで働き、いつ家を空け、だいたい誰を訪ねているかまで見えてきます。これは仮定のリスク像ではなく、地図に線を引くアプリが標準的に生み出す出力そのものです。

位置情報の許可を一度も求めないアプリは、そうした履歴を貯めようがありませんし、集めていないものを漏らすことも、売ることも、提出を求められることもできません。ウォーキングアプリは好きだけれど歩行記録は残したくない——そう感じるなら、「位置情報の許可なし」はどんなプライバシーポリシーよりも明快な保証です。

実践のポイント

  • 歩数カウントは低消費電力のモーションコプロセッサで動いており、実質タダ。ヘルスケアからそれを読むアプリも同じです。
  • 本当のコストはGPS。継続的な無線測位で、たいてい画面はオン、ときにはバックグラウンドでも動きます。
  • 真犯人は設定 → バッテリーで、「画面オン」と「バックグラウンド」の内訳を読んで見つけましょう。
  • 設定 → プライバシーとセキュリティ → 位置情報サービスを点検し、理由なく「常に」になっているものは格下げを。
  • 位置情報を求めてくる歩数トラッカーは、バッテリーにとってもプライバシーにとっても、必要のないものを求めています。
