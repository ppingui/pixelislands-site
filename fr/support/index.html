Questions fréquentes

Mes pas ne se mettent pas à jour

Pixel Islands lit vos pas dans Apple Santé. Vérifiez que l'autorisation est bien accordée dans l'app Santé : Profil → Apps → Pixel Islands → autoriser « Pas ». Ouvrir l'app Santé une fois peut aussi aider les données du jour à se synchroniser depuis l'Apple Watch.

J'ai changé de téléphone — où sont mes îles ?

Votre progression est sauvegardée avec iCloud. Connectez-vous avec le même identifiant Apple, installez Pixel Islands, et votre collection se synchronisera automatiquement.

Comment restaurer mon achat Premium ?

Ouvrez les Réglages dans l'application et touchez « Restaurer les achats ». Assurez-vous d'être connecté avec le même identifiant Apple que celui utilisé pour l'achat d'origine.

Comment gérer ou résilier mon abonnement ?

Les abonnements sont gérés par Apple : Réglages de l'iPhone → votre nom → Abonnements → Pixel Islands. Vous pouvez aussi demander un remboursement via reportaproblem.apple.com.

Comment mes données de santé sont-elles traitées ?

Nous lisons uniquement votre nombre de pas, et uniquement pour faire grandir vos îles. Rien n'est vendu ni utilisé à des fins publicitaires — les détails figurent dans notre politique de confidentialité.

J'ai une idée de thème d'île !

Nous adorons ça. Envoyez-la à supportpixelislands@gmail.com — le prochain thème sera peut-être le vôtre.
